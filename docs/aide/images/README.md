# Illustrations de l’aide ECU MEMS Manager SESSION

Déposer ici les **captures d’écran validées** du logiciel (PNG de préférence, JPEG accepté), par exemple :

- `apercu.png`
- `injection.png`
- `reglages.png`
- `ia_mems.png`
- `base_donnees.png`
- `mise_a_jour_base.png`

Le système CMake détecte les images de ce dossier et les intègre **automatiquement au Setup Windows**, sous le chemin de ressource `:/help/images/<nom du fichier>`. Elles restent disponibles **hors ligne**.

Après ajout d’une image, il suffit de référencer son nom dans `help.html.in` ou `help_en.html.in` pour qu’elle apparaisse au bon chapitre du guide. Ne pas utiliser d’image publique hébergée sur Internet. Les captures ne doivent contenir ni secrets ni données personnelles.

La présente version du guide fonctionne sans illustration : aucune image vide ou fictive n’est affichée avant réception des captures.
